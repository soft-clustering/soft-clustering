HOW TO RUN THE TEST SUITE
=========================

1. Install the test dependencies:

       pip install -e ".[dev]"

   Add the deep-learning extra to include the four PyTorch estimators (CDCGS,
   DMoN, NOCD, RDFKC); without it their tests are skipped, not errored:

       pip install -e ".[dev,deep]"

2. Run everything:

       pytest

3. With coverage:

       pytest --cov=soft_clustering --cov-report=term-missing
       pytest --cov=soft_clustering --cov-report=html   # then open htmlcov/index.html

4. One layer or one estimator:

       pytest tests/test_protocol.py            # conformance, every estimator
       pytest tests/test_recovery.py            # planted-structure recovery, every estimator
       pytest tests/test_external_agreement.py  # agreement with scikit-fuzzy, scikit-learn, evclust
       pytest tests/test_fcm.py -v              # one estimator

The optimization-equivalence tests for SoftDBSCANGM take a few minutes; skip
them while iterating with

       pytest --deselect tests/test_optimization_equivalence.py::TestSoftDBSCANGM


WHAT THE SUITE COVERS
---------------------

- test_protocol.py            the estimator contract for every exported estimator:
                              output shapes and semantics, partition constraint,
                              reproducibility, refit idempotence, untouched global
                              random state, inputs not modified, out-of-sample
                              behaviour, clone round-trip
- test_recovery.py            every estimator recovers planted structure
- test_external_agreement.py  agreement with independent implementations
- test_<algorithm>.py         each method's equations, invariants and regressions
- test_edge_cases.py          numerical edge cases: a valid result or a clear error
- test_registry.py            the algorithm table matches the code
- test_examples.py            every script in example/ runs
- test_benchmarking.py        soft_clustering.benchmarking
- test_optimization_equivalence.py
                              optimized implementations match preserved references

Coverage is reported by CI; the figures quoted in the paper are regenerated by

       python tools/paper_stats.py --with-coverage
