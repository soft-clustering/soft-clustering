# Manuscript sources

`scpp.tex` is the revised manuscript. Build it with `jmlr2e.sty` and a
`sample.bib` on the path:

```bash
pdflatex scpp && bibtex scpp && pdflatex scpp && pdflatex scpp
```

## Before building

1. **Merge the bibliography.** `references-additions.bib` contains six new
   entries and five *replacements* for existing keys whose provenance pointed
   at reprints rather than originals. The replaced keys are renamed in
   `scpp.tex`, so both files must be updated together:
   `bezdek2013pattern` → `bezdek1981pattern`,
   `krishnapuram2002possibilistic` → `krishnapuram1993possibilistic`,
   `hofmann2013probabilistic` → `hofmann1999plsa`.

2. **Figures and tables are already staged here.** The three PDFs are copied
   from `optimization/figures/`; `tables/` holds the two generated tables the
   paper `\input`s. All five are regenerated by the commands below.

## Regenerating every number in the paper

```bash
python optimization/analyze.py            # optimization tables and figures
python benchmarks/run_main_benchmark.py   # cross-family comparison
python benchmarks/run_external_baselines.py
python tools/check_paper_numbers.py --full
```

`check_paper_numbers.py` recomputes each quantitative claim from the
repository and compares it against the value written in `scpp.tex`, failing if
they disagree. It runs in CI, so a stale number breaks the build rather than
reaching a reviewer. The previous revision reported 532 tests across 42
modules when the repository had 687 across 44, and said eighteen algorithms
ran in under 10 ms when its own `results.csv` said fourteen; this script is
the mechanism that prevents a repeat.
